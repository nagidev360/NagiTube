# NagiTube

A YouTube-inspired Android video app prototype built with Kotlin and Jetpack Compose.

## Planned Features
- Google Sign-In (Supabase Auth integration planned)
- Custom dark theme
- Video player for authorized media
- Background playback
- SponsorBlock integration for supported playback sources
- Authorized offline downloads

## Development status
Starter Android app scaffold. Backend, authentication, video catalog, and player integrations are not configured yet.

## Build
Open this repository in Android Studio with Android SDK installed, or configure a compatible cloud Android build environment. The app uses Gradle and Kotlin.

## Security and rights
Never commit API secrets, OAuth client secrets, or service-role keys. Only host or download media you own or have permission to use.
